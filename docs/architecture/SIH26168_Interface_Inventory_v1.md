# SIH26168 Interface Inventory v1

**Contract status:** conceptual v1 baseline; implementation schemas are WP-01.  
**Compatibility:** major versions reject incompatibility; additive optional fields increment minor; units/frame/clock/sequence changes are always major plus ADR.

## Global rules

- Scalar units are SI unless the field says otherwise. Geodetic latitude/longitude are decimal degrees in WGS84; local navigation is fixed-origin NED.
- Quaternions are Hamilton active rotations, scalar-first `[w,x,y,z]`, canonical `w≥0`. S2 state/error ordering is immutable.
- Scientific epochs are signed 64-bit nanoseconds in an identified monotonic domain. Wall/UTC is metadata only.
- Evidence IDs are non-empty and consumed on first presentation, including malformed/gated items.
- Replay preserves original source sequence/time/provenance; recomputed derived records declare the new algorithm/config.

## Interface-to-component completeness

Every consumed/provided ID is validated against `machine_readable/interfaces.json`; external user display and reports are deliberately not runtime contracts. C-20 owns schema governance but does not become the runtime producer of scientific data.
